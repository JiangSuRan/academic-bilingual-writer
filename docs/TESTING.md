## 六、已知限制

1. **平台**:仅打包/测试了 Windows 10/11(x64);Linux/macOS 未验证。
2. **代理**:AI 请求强制 `no_proxy()` 直连,不读取系统/环境代理;如需经代理访问 OpenAI 官方端点,当前版本不支持(国内兼容端点不受影响)。
3. **对话框自动化**:tauri-plugin-dialog 的 save 在本机挂起已绕过(rfd 直连);纯人工操作无感知。
4. **DOCX 导出**:按需求第一版不做,Word 粘贴纯文本后人工排版。
5. **并发**:批量翻译严格串行(防限流),大量段落时耗时较长。
6. **自动翻译**:仅对「未翻译」段触发;中文已修改的段落永远需要手动确认(设计使然,防覆盖)。
7. **历史版本**:备份保留最近 20 份/文稿,更早的自动清理;无内置浏览/恢复 UI(文件在 `%APPDATA%\com.medsci.abw\backups\<docId>\`)。
8. **未签名**:安装包无代码签名证书,Windows SmartScreen 可能提示"更多信息→仍要运行"。
9. **模型提示词依从性**:统计红线靠提示词约束,不做事后校验;重要数值建议人工核对(医学写作场景必须)。
10. **移动段落**:暂无上移/下移按钮(ID 机制已支持,界面入口留待后续版本)。
