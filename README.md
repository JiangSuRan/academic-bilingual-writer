# Academic Bilingual Writer · 学术双栏写作台

一款面向医学科研人员的**中英双栏 SCI 论文写作桌面应用**。左侧用中文组织研究思路,右侧获得对应的学术英文;英文始终可以直接编辑,完成后以纯文本一键复制进 Microsoft Word。

不是 Markdown 编辑器,不是 LaTeX 编辑器,不是 PDF 翻译器,也不是文献管理软件,更不试图替代 Word——它只做好一件事:让中文科研写作与英文论文表达在同一个窗口中高效协作。

## 核心特性

- **双栏一一对应**:每对中英段落持有稳定唯一 ID;插入、删除、拆分、合并段落都不会导致错位(不依赖行号或数组索引)。
- **段落状态机**:未翻译 / 已生成 / 中文已修改 / 英文已人工编辑 / 翻译中 / 生成失败,六态一目了然。
- **防覆盖机制**:
  - 中文修改后旧英文**保留并标记"需更新"**,绝不自动删除;
  - 英文一经人工编辑,AI **永不自动覆盖**该段;
  - 重译/润色结果先进入"待确认缓冲",你比较后决定**替换或保留原稿**。
- **AI 能力**(OpenAI 兼容接口):段落生成、批量翻译未译段(严格串行防限流)、学术润色、语法检查、保留原意简化;流式输出可中途停止;失败可重试且不清空任何已编辑文本。
- **医学 SCI 提示词**:内置肿瘤学、临床医学、生物信息学、分子生物学、转录组学、单细胞组学场景的翻译规范——保留全部研究事实与统计信息(P/HR/OR/95% CI),严格区分相关与因果,`associated with` 绝不升级为 `promotes/induces/drives`,禁用夸大措辞;按 Abstract/Introduction/Methods/Results/Discussion 分节施加风格约束。
- **术语表**:`中文 => English` 每行一条;仅当前段落中出现的术语才会随请求发送(省 token、防干扰)。
- **上下文衔接**:自动携带上一段的中文与英文(有界截断)作为参考,保证跨段术语一致。
- **纯文本复制**:复制当前段 / 所选 / 全部英文,不含 Markdown、HTML、隐藏格式;基因名、希腊字母、统计符号原样保留。
- **本地文稿**:`.abw.json` 单文件格式(UTF-8,易于检查);自动保存(1.2s 防抖)+ 原子写入(临时文件 + rename)+ 每文稿保留 20 份历史备份;重启自动恢复上次文稿;导出英文 TXT 与中英对照 TXT。
- **安全**:API Key 存入 **Windows 凭据管理器**,不落明文文件;日志不记录密钥与文稿内容;无遥测,仅在你主动触发 AI 操作时发送必要文本。
- **多模型配置**:内置 OpenAI / DeepSeek 预设,可添加任意 OpenAI 兼容端点(DeepSeek、Qwen、OpenRouter、自定义),顶栏一键切换;连接测试即时验证。

## 界面

三段式布局:顶部工具栏(文件、文稿状态、模型切换、批量翻译、复制、设置)+ 中部双栏编辑器(可拖拽分隔线、双侧独立字号、明暗主题)+ 按需弹出的设置面板。界面语言为中文。

## 快速开始

### 用户安装

从 `releases/` 目录获取 `Academic Bilingual Writer_0.1.0_x64-setup.exe`(NSIS,当前用户安装,无需管理员权限),双击安装即可。需要 Windows 10/11(系统自带 WebView2,通常无需额外安装)。

首次使用:

1. 点击右上角 **设置**;
2. 选择或添加模型服务,填写 Base URL、模型名与 API Key,**保存密钥**;
3. 点击 **测试连接** 确认可用;
4. 开始写作:左栏输入中文 → 选中段落后 `Ctrl+Enter` 生成英文(或开启自动翻译);
5. 完成后 **复制英文** 粘贴进 Word。

### 开发者构建

依赖:Node.js ≥ 20、Rust stable (msvc)、Windows C++ Build Tools、WebView2。

```bash
npm install
npm run tauri dev      # 开发调试
npm test               # 前端单元测试(vitest)
npm run build          # tsc 类型检查 + vite 前端构建
cd src-tauri && cargo test   # Rust 单元测试
npm run tauri build    # 生成 Windows 安装包(NSIS)
```

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Enter` | 生成/重译当前段落(中文输入法组合期间不触发) |
| `Ctrl+S` | 立即保存 |
| `Ctrl+N` | 新建文稿 |
| `Ctrl+Shift+C` | 复制全部英文 |
| 中文区 `Enter` | 在光标处拆分为两段(`Shift+Enter` 为段内换行) |
| 中文区段首 `Backspace` | 并入上一段 |

## 文稿格式

`.abw.json` 为带格式版本号的 UTF-8 JSON:每对段落含 `id / zh / en / enSourceZh(生成快照)/ enEdited(人工编辑标记)/ enPending(待确认新译)/ scene(写作场景)`。`enSourceZh` 使"中文已修改"状态在关闭重开后依然正确;备份位于 `%APPDATA%\com.medsci.abw\backups\<docId>\`。

## 隐私与安全

- 仅在你执行生成/润色/连接测试时,向**你自己配置的**模型服务发送当前段落文本、上一段摘录与命中的术语条目;
- API Key 通过 keyring 存于系统凭据管理器;
- 不含任何遥测、自动更新检查或云账户。
